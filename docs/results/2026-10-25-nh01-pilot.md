## Verdict (binding cell: T = 0, cue with 10 % flipped bits, N = 256, t = 10, 10 seeds)

|---|---|---|---|

| C2 monotone in t | median α̂_c(dream, t) non-decreasing up to one grid step (0.05) | medians 0.176, 0.268, 0.422, 0.566, 0.600, 0.559, 0.522 for t = 0, 0.3, 1, 3, 10, 30, 100 ; largest consecutive drop 0.041 | **holds** (within tolerance ; see caveat 1) |

| Overall | confirmed iff C1 ∧ C2 ∧ C3 | | **confirmé** |
| P4 spurious (secondary label) | fraction of spurious final states at α ∈ {0.10, 0.14} reduced ≥ 50 % under dream t = 10 vs Hebb | α = 0.14 : Hebb 0.119 [0.066, 0.181] → dream 0.000 ; α = 0.10 : 0.004 → 0.000 (floor effect, uninformative) | holds |

The pilot **demonstrates**, under the pre-registered rule, that the dreaming kernel at t = 10 raises the empirical capacity of the ±1 Hopfield network by a factor ≥ 3 over the Hebbian kernel at N = 256, and that the Frobenius-matched uniform shrink leaves it exactly unchanged. It does **not** refute anything: the catalogue's refutation conditions (shrink ≥ 2×, gain < 0.1, non-monotone beyond tolerance) are not met. C3 at T = 0 is a numerical verification of a theorem (sign invariance), not an empirical discrimination ; the empirical content is on the dreaming side and in the finite-temperature arm below.

## Descriptive results (not covered by the decision rule)

- **All sizes, T = 0, 10 % cue.** Ratio at t = 10 : N = 64 → 3.13 [2.74, 3.57] ; N = 128 → 3.38 [3.21, 3.53] ; N = 256 → 3.43 [3.26, 3.60]. Hebb α̂_c decreases with N (0.211, 0.179, 0.175) ; dream α̂_c too (0.632, 0.602, 0.599).
- **Finite temperature (Glauber, T = 0.2, 10 % cue), N = 256.** Hebb 0.137 [0.132, 0.141] ; dream t = 10 → 0.449 [0.444, 0.453], ratio 3.30 [3.20, 3.39] ; shrink c(10) → 0.134, ratio 0.980 [0.973, 0.989]. The shrink arm now moves, and in the direction theorem 2 predicts (c < 1 ⇒ warmer ⇒ slightly lower capacity). The control is therefore not vacuous at T > 0 and still falls far below 1.1×.
- **Stability of the stored patterns (cue = pattern, T = 0).** Hebb 0.197 [0.188, 0.206] at N = 256 ; dream t ≥ 10 is **censored at the grid maximum 0.95** on all seeds and all N (every stored pattern is a fixed point up to α = 0.95), consistent with the projector limit of the kernel. The ratio is therefore only a lower bound (≥ 4.86 at N = 256).
- **Spurious attractors and convergence (N = 256, 10 % cue).** Hebb : spurious fraction 0.12 at α = 0.14, 0.71 at α = 0.20, 1.00 from α = 0.30 ; dream t = 10 : 0.00 up to α = 0.45, 0.05 at 0.50, 0.52 at 0.60. Sweeps to convergence : dream 2–3 vs Hebb 5–24 at the same loads.
- **Matched shrink factor.** c_fro(t = 10) at N = 256 : 0.944 (α = 0.10), 0.920 (0.14), 0.882 (0.20), 0.817 (0.30), 0.676 (0.50), 0.600 (0.60) ; the spectral factor is always lower (0.23–0.82), as anticipated in the pre-reg.
- **Energy.** Under its own kernel the dreamed network's final states sit higher (−0.45 vs −0.50 at α = 0.10, N = 256) because the dreamed kernel has a smaller norm ; under the Hebbian kernel the dream-arm final states stay at ≈ −0.495 for all loads up to 0.5, whereas the Hebbian arm's spurious states dig deeper minima as α grows (−0.65 at α = 0.30, −0.81 at 0.60). Energy is reported, not interpreted.

## Caveats

1. **Non-monotonicity beyond t = 10.** On every N and both temperatures the capacity peaks at t = 10 and then decreases (N = 256, T = 0 : 0.600 → 0.559 → 0.522 at t = 30, 100). The drop per grid step (≤ 0.041) is inside the pre-registered tolerance, so C2 holds, but the trend is systematic. The catalogue's « monotone en t » should be re-stated as « non-decreasing up to a finite optimum » for the N = 1 000 run ; with the diagonal removed, the large-t (projector) limit is known to shrink basins.
2. **Finite-size estimator.** The T = 0 Hebbian α̂_c (0.175 at N = 256) is above the thermodynamic 0.138 because the estimator asks for half of 32 probes to be retrieved from an 80 % cue at finite N. All criteria are paired ratios within N, so this does not affect the verdict, but absolute capacities must not be compared with the literature value. The T = 0.2 Hebbian estimate (0.137) coincides with 0.138 by accident of threshold choice.
3. **P4 at α = 0.10** is a floor effect (Hebb already at 0.004) ; only α = 0.14 is informative.
4. **Not tested :** N = 1 000, the VQ-codebook/MI part of NH-01, `recombine`, any learning rule other than Hebb, correlated patterns. The dreaming kernel's gain on correlated patterns (where the catalogue expects an interior optimum) is the natural next cell.
5. **Shared host.** Load average ≈ 20 from other jobs during the run ; wall time is not a benchmark.

## Implementation notes

- Ties at zero field are detected with a tolerance 1e-12 · N · max|J|, identical for every arm, so that the sign rule is exactly invariant under J → cJ (Hebbian fields are exact multiples of 1/N, c/N multiples are not). Found by the pre-run smoke check (51 of 288 shrink cells diverged from Hebb before, 0 after) ; fixed before the run, no amendment needed since no run had started.
- Paired design : same patterns (nested in α), cues and update orders for all 13 arms of a cell. Capacities per seed, seed-level percentile bootstrap (10 000 resamples, seed 20261025).
